# Digital Link Studio

Marketing website for Digital Link Studio. Plain HTML, CSS and JavaScript with no build step.

## Structure

```
index.html        Homepage
css/styles.css    All styles, starting with design tokens (colors, fonts, spacing)
js/main.js        Site scripts (mobile menu)
assets/images/    Photos and graphics
assets/icons/     Logo, favicon and icons
assets/fonts/     Self hosted fonts (currently loaded from Google Fonts)
```

## Preview locally

Open `index.html` in a browser, or run a local server from this folder:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.
